SEFIK EGRIBOZ — PERSONAL PORTFOLIO (OFFLINE PREVIEW)
=====================================================

WHAT IS INSIDE
  index.html       The website — double-click to open in your browser
  style.css        Styling and responsive layouts
  script.js        Small interactive role-focus controls and mobile navigation
  assets/          User-supplied high-resolution PNG portrait and favicon
  cv/              Five supplied role-specific PDF CVs

HOW TO PREVIEW ON WINDOWS
  1. Extract the entire ZIP file to a folder, e.g. Desktop\sefik-portfolio.
  2. Open that folder.
  3. Double-click index.html.
  4. It should open in Chrome, Edge or your default browser.
  5. Navigate via the header. Select the focus buttons to compare five career perspectives.
  6. Use the CV download links to open/save the corresponding PDF.

No installation, internet connection, Node.js, Python, Git or domain is needed.
Keep the files together; index.html needs style.css, script.js, assets/ and cv/.

OPTIONAL: Local web server for testing
  If Python is installed, open a terminal in this folder and run:
      py -m http.server 8000
  Then open http://localhost:8000
  (Not required for ordinary preview.)

PUBLICATION NOTES
  - This is only a local preview. Nothing has been uploaded to the Internet.
  - Email and LinkedIn use the contact data in the supplied CVs.
  - The CVs include a phone number and other personal details. Review before publishing.
  - Metrics and outcomes on the site are based on the supplied CVs, not third-party audits.
  - Five supplied PDF CVs are included in full, without reformatting or conversion.
  - DOCX files are intentionally excluded from this package.
  - For public deployment, add a domain after you approve the site content.

CV VERSIONS
